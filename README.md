# dotfiles
Config files for my dev environment. Managed by symlinks.
It handles distro detection, TTY detection, idempotent plugin installations.


## Including:
- `.wezterm.lua`
- `.zshrc` + `.p10k.zsh`
- `.vimrc` + `vim/`
- `.gitconfig`
- A bash script `install.sh`: file system, packages, symlinks
